# 模块 HTML 编写指南

> 面向**站长本人**：在后台「模块管理」里写一个首页模块的 HTML / CSS / JS。
> 相关实现见 [home-modules-spec.md](home-modules-spec.md)、坑位见 [pitfalls.md](pitfalls.md)、
> 详细样式字段见 `main/src/lib/home/style.ts`。日期：2026-10-02。

## 1. 三分钟上手

1. 后台 **模块管理 → 新建模块** → 选一个模板（空白 / 图文卡片 / 通栏横幅 / 弹出模块 / 推荐应用）。
2. 左栏改名字、调「基本样式」（字体、字号、颜色、按钮、圆角）。
3. 右栏写 HTML / CSS / JS —— 或者点「导入文件」把现成的 `.html` / `.css` / `.js` 拉进来。
4. 点 **保存模块**，再到 **首页管理** 把这个模块拖到格子里、勾上启用。
5. 前台首页刷新看效果；手机上也要看一眼（版式可以由你自己写媒体查询控制）。

三条最容易踩的：

- **`<script>` 写进 HTML 栏不会执行**（浏览器语义）——要跑脚本就写进 JS 栏。
- **你的 CSS 默认会被限在本模块内**（勾选框「CSS 只作用于本模块」）。取消勾选就全站生效。
- **改了不生效**先看两件事：模块是不是「已启用」、浏览器的强刷（Ctrl+F5）。

## 2. 模块长什么样

一个模块在前台渲染出来是这样一个盒子（`HomeGrid` 的格子）：

```html
<div class="home-grid__cell ...">          <!-- 格子：宽度/高度由首页管理里的几何决定 -->
  <div class="home-module ..." style="--mod-*: ..." data-mod-style="--mod-text ...">
    <!-- 你写的内容 + 积木 + CustomModuleRuntime（你的 HTML/CSS/JS） -->
  </div>
</div>
```

要点：

- **盒子决定内容**。高度在「首页管理」里按**像素**给（滑块与数字框都是 px）；**填 0 = 高度自适应**，由内容自己决定（推荐给内容长度会变的模块）。给了固定高度就按那个高度排，内容超出会被裁掉——矮格子会自动收手（先收紧间距、再撤掉装饰），但**别指望它自己撑开**。
- **首页大图（Banner）是例外**：它的高度由自己的「高度」选项给（满屏 100vh / 大 70vh / 中 420px），格点高度恒为 0（格子跟着它走）。给 banner 的格子填像素高度会把满屏底图钉死。
- 内容的宽度不固定（同一个模块在 12 列大屏和手机上宽度差 3 倍），所以**别写死像素宽**，
  用 `%` / `flex` / `grid` / `clamp()`。
- 自己写模块时，**想让卡片撑满格子的高度就用 `height: 100%`**（固定高度的格子会把高度送到内容）；想让内容决定高度就把高度留 0。

## 3. HTML 栏

- 原样插入到模块内部。可以写多个顶层元素，但**包一层自己的根元素**最省心
  （CSS 限定范围、JS 取元素都方便）：`<div class="my-card">…</div>`。
- 图片：本地上传的图走 `/api/uploads/...` 地址，外链只允许 `https://`。
- 链接：站内写 `/posts`、`/moments`、`/pages/xxx` 这种路径；外链 `https://`。
- 不要在这个模块里再写 `<html>` / `<head>` / `<body>`：它是页面里的一个盒子，不是独立页面。

### 站点数据能用吗

HTML 栏是静态的：想要「最新文章列表」这类**真实数据**，用「积木」里的
`文章大卡` / `文章宫格` / `最近发布` / `分类列表` / `标签云` / `站点统计`
（它们是复用前台组件渲染的，会跟着数据变）。积木与自己的 HTML 可以同时用，
顺序是「先积木、后代码」。

## 4. CSS 栏

- 默认**限定在本模块内**：实际编译成 `.home-custom--<模块slug>{ 你写的所有规则 }`。
  所以直接写 `.my-card { … }` 就行，不用自己加前缀。
- ⚠️ 因为上面这层包裹，**`@media` 写在外面也没问题，但 `@keyframes` / `@font-face`
  这类不能嵌套的规则会被包进去而失效**。需要它们时：取消勾选「只作用于本模块」，
  自己给选择器加前缀（例如 `.home-custom--app-promo .my-card`）。
- 站点已有的全局样式仍然生效（`img`、`a`、`p` 的默认边距等）。要压过它们就写具体一点的选择器。
- 想全站生效（比如定义一个工具类）就取消勾选「CSS 只作用于本模块」——但这时要自己
  控制影响范围，别写 `*` 或裸 `p` 这种大范围选择器。

### 4b. 能用的 CSS 变量

**模块自己的（推荐用这些，自动跟随你在「基本样式」里的配置）**：

| 变量 | 含义 | 不配时的兜底 |
|---|---|---|
| `--mod-bg` | 模块背景色 | 站点卡片色 |
| `--mod-bg-image` | 背景图（`url(...)` 形式） | 无 |
| `--mod-bg-dim` | 背景图压暗比例（0–0.9） | 0 |
| `--mod-text` | 正文色 | 站点次要文字色 |
| `--mod-heading` | 标题色 | 站点正文色 |
| `--mod-accent` | 强调色 | 站点主题色 |
| `--mod-radius` | 圆角 | 站点圆角 |
| `--mod-padding` | 内边距 | 无（用你自己的） |
| `--mod-font` | 字体栈 | 继承站点 |
| `--mod-font-size` | 基准字号 | 继承站点 |
| `--mod-btn-bg` | 按钮底色 | `--mod-accent` |
| `--mod-btn-text` | 按钮文字色 | `#fff` |
| `--mod-btn-radius` | 按钮圆角 | `--mod-radius` |
| `--mod-btn-width` / `--mod-btn-justify` | 按钮占满一行时的宽/对齐 | 不占满 |

用法：`color: var(--mod-text, var(--heo-secondtext));` —— **后面那个兜底值就是站点主题**，
所以「站长没配」时外观与站点保持一致。

**站点主题变量（`--heo-*`，可以读，也可以在自己的范围内改）**：

`--heo-theme`（主色）、`--heo-text`、`--heo-secondtext`、`--heo-card-bg`、`--heo-card-border`、
`--heo-radius`、`--heo-shadow-border`。明暗主题下它们会自动换值——**想让模块跟随主题切换，
就用它们而不是写死颜色**。

> 内部机制（好奇再读）：你在「基本样式」里配过的项会以 `--mod-*` 内联写在模块盒子上，
> 同时盒子上有 `data-mod-style="--mod-text --mod-radius"` 表示「这些项用户配过」。
> 站点 CSS 只在这些项确实配过时才生效，所以**没配过 = 完全跟随主题**。

## 5. JS 栏

- 在浏览器执行，外面套了 `try/catch`：**报错只打印日志，不会连坐整页**。
- 执行时机：模块挂载后、每次保存/刷新后重跑一次（组件重新挂载）。**没有卸载钩子**——
  如果你加了 `setInterval` / `window.addEventListener`，请自己留清理办法
  （例如把定时器挂在元素上、用 `data-*` 标记避免重复绑定）。
- 拿自己的根元素：

```js
const root = document.querySelector(".home-custom--app-promo"); // ← 换成你的模块 slug
if (root) {
  root.querySelectorAll("[data-copy]").forEach((node) => {
    node.addEventListener("click", () => navigator.clipboard?.writeText(node.dataset.copy));
  });
}
```

- 别做这些事：改 `document.title`、劫持全局 `setTimeout` / `addEventListener`
  （会影响 React 与全站其它模块）、往 `body` 上挂大块 DOM。

## 6. 积木可用到哪些类名

积木渲染出来用的是站点自己的组件，类名可以直接拿来写 CSS：

| 积木 | 主要类名 |
|---|---|
| 标题 / 段落 | `.home-block__heading` / `.home-block__text` |
| 按钮 | `.heo-button`（`variant: ghost` 时是 `.heo-button--ghost`） |
| 图片 | `.home-block__image`（内部是 `.cover-media`） |
| 分隔线 | `.home-block__divider` |
| 文章大卡 | `.post-card` / `.post-card--plain` / `.post-list` |
| 文章宫格 | `.dash-recommend` / `.mini-card` |
| 分类 / 标签 / 站点 / 最近发布 | `.widget` + `.widget__title` 等（与侧栏同一套） |

自己写 HTML 时**也可以直接用 `.heo-button`**：

```html
<a class="heo-button" href="/posts">去看看</a>
```

这样「基本样式」里的按钮配色会自动作用于它（按钮的 `--mod-btn-*` 只接管 `.heo-button`）。

## 7. 覆盖层（弹出模块 / 推荐应用）

「弹出模块」和「推荐应用」这两个模板建出来的模块**不占格点**，而是浮在页面上（覆盖层）：

- 出场边、几秒后出现、关闭叉叉、关闭后是否记住 —— 在 **首页管理** 左栏配（模块自己的 `config`）。
- 宽度由格点里的「列跨度」决定（4/12 列 ≈ 视口的 1/3，夹在 280–440px）；贴左/居中/贴右由列位置决定。
- **垂直位置由「从哪出现」决定**，格点的行不影响它。
- 手机档统一贴底满宽。
- 你只负责卡片里的内容；外层的定位/动画/关闭按钮由 `PopupShell` 负责。
- 需要在 CSS 里控制外壳（比如把默认白底换成自己的）时：

```css
.my-card {
  background: var(--mod-bg, #fff);
  border-radius: var(--mod-radius, 18px);
}
```

> 不想用外壳的玻璃底？在模块配置里关掉「外层套玻璃卡片」（`card: false`），
> 外壳会变成纯定位容器（`.home-popup--plain`），卡片外观完全由你决定。

## 8. 导入文件

「导入文件」支持 `.html` / `.htm` / `.css` / `.js` / `.mjs` / `.txt`，各栏上限 **32KB**：

- 导入 HTML 时会自动把里面的 `<style>` 段搬到 CSS 栏、`<script>` 段搬到 JS 栏
  （带 `src=` 的外链脚本留在 HTML 里不动），并告诉你搬了几段。
- 导入只是把内容填进编辑框，**要点「保存模块」才生效**。
- 超上限会截断并给出提示——宁可少一段，不整份丢掉。

## 9. 十三个坑（都踩过）

1. **`<script>` 放 HTML 栏不执行** —— 浏览器对 `innerHTML` 的语义如此，脚本写 JS 栏。
2. **JSON / 引号**：HTML 里的 `"` 不用转义；但写进 JS 字符串时要自己注意引号配对。
3. **CSS 不生效**：① 勾了「只作用于本模块」又写了 `body {}` 这类选择器；② 用了 `@keyframes`
   而它在作用域包裹里；③ 被站点同名类（如 `.post-card`）按顺序压掉——加一层自己的根元素即可。
4. **弹窗点不动**：出场延迟期间外壳是 `pointer-events: none`，延迟结束自动摘掉；
   如果你自己给卡片写了 `pointer-events: none`，记得成对回收。
5. **弹窗被 Banner 盖住**：覆盖层必须是带 `z-index` 容器的**兄弟**，别把它塞进某个带
   `z-index`/`transform` 的祖先里（会给它造层叠上下文或包含块）。
6. **`width: min(50%, max-content)` 无效**：`min()/max()` 只吃长度，intrinsic 关键字会让
   **整条声明被静默丢弃**。要「一半起步、内容撑开」用
   `width: fit-content; min-width: 50%; max-width: 100%; justify-self: start;`。
7. **固定高度里溢出**：给模块配了高度（px > 0）就别再让内容无限长，用 `overflow: hidden` 或
   `min-height: 0` + `overflow: auto`。矮格子里的装饰性元素（泡泡、插画）记得 `flex: 0 0 auto`，
   不然会被压成扁片。
8. **中文换行**：窄盒子里长英文/URL 会撑破，加 `overflow-wrap: anywhere`。
9. **`p` 有默认上下边距**（站点全局样式），要精确排版就自己 `margin: 0`。
10. **图片变形**：`<img>` 用 `object-fit: cover/contain` + 明确的 `aspect-ratio`，
    别指望默认的 `max-width: 100%` 帮你摆好。
11. **本地图片地址**：粘贴本地上传后的 `/api/uploads/...` 路径，不要写 `data/uploads/...`
    这种服务器文件系统路径（前台访问不到）。
12. **改了没变化**：先确认保存成功（按钮变成「已保存」），再强刷；覆盖层模块还有
    「关闭后不再出现」的 localStorage 记忆（键 `myblog:popup:<slug>`），清掉才看得到。
13. **别在模块里依赖其它模块的 DOM / 变量**：模块是独立渲染的，顺序不保证。

## 10. 发布前自检

- [ ] 保存成功，首页管理里该模块**已启用**（覆盖层模块还要看「从哪出现」与延迟）。
- [ ] 电脑宽屏、手机窄屏各看一次（窄屏尤其看长文案有没有被裁）。
- [ ] 明暗主题各看一次（用主题按钮切），文字对比度还够。
- [ ] 有数据的内容（文章/瞬间/分类）不是空的。
- [ ] 弹窗能关掉，关掉后不再挡住后面的点击。
- [ ] 浏览器控制台没有红色报错（模块 JS 报错会打印 `[home-module:<slug>]`）。

## 11. 常见问答

**Q：能不能用别的 CSS 框架 / CDN 脚本？**
A：技术上可以（在 HTML 里加 `<link>` / 带 `src` 的 `<script>`），但站点是 1GB 内存的自建站点，
引外部资源会让首页变慢、且断网/被墙时模块白屏。建议只用站点自己的类名与变量。

**Q：能不能做一个自己的独立页面，而不是首页模块？**
A：可以，走后台 **页面管理**（静态页面，同样是 HTML/CSS/JS 三栏），地址是 `/{目录}/{slug}`。
两者的代码写法一样，区别只是：模块渲染在首页格子里，静态页面渲染在独立路由上。

**Q：想改「推荐应用」那个内置卡片，但它是内置模块，能改吗？**
A：能。推荐应用是**可编辑的内置模块**：打开它的编辑页就能改 HTML / CSS / JS 与基本样式；
点「填回出厂代码」可以恢复。其它内置模块（文章卡片、瞬间等）是 React 组件，不能改代码，
只能在首页管理里调选项。

**Q：模板建出来的模块和手写模块有区别吗？**
A：没有。模板只是**新建时的初值**（一份出厂代码 + 初始配置 + 默认几何），
落库后就是普通自建模块——模板日后改写法不会影响已经建好的模块。
