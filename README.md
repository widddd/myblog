# MyBlog — 个人博客系统

基于 Next.js 16 的个人博客：前台（主页/瞬间/文章/全局搜索/留言板）+ 后台（文章管理、mdx-editor 富文本发布、评论审核、自动备份、程序更新）。设计风格参考 theme-hao（Heo 风格圆角卡片 + 丝滑动效）。

> 站长高级用法与注意事项见 **[docs/user-manual.md](docs/user-manual.md)**（备份加密、程序更新、COS、自定义模块等）。AI 协作请先读 [AGENTS.md](AGENTS.md)；文档索引见 [docs/README.md](docs/README.md)。进度见 [PLAN.md](PLAN.md)。

## 特性

- **前台**：主页（可在后台自由排布的模块化格点：Banner + 欢迎 + 瞬间 + 文章卡 + 侧栏 widget；推荐文章默认关闭）、文章列表/分类/标签/归档、瞬间（瀑布流/朋友圈宫格/点赞）、**相册**、留言板、⌘K 搜索（密码文仅标题）。Banner 底图完全加载后再播出场动画；加载超过 2 秒才用与后台上传相同的顶栏进度条，满格后自动关掉；文章卡悬停只扫一道光泽，移开不回放；**只有真正没封面的文章**（文章设置里选「封面图」又没选图）才不留渐变占位，改成窄窄一条：只显示标题和文章开头一小段，开头那行从左到右渐渐模糊变淡（没写摘要就自动取正文开头）；选了「纯色 / 混色」的文章照样是大卡，封面位画作者选的色块；**两种卡片的右下角都有时间**，只给相对时间（最近 / 几天前 / 几个月前），无封面细条卡也一样；首页的分类、标签和「瞬间」徽标可在后台「设置 → 首页外观」统一调颜色与底色不透明度
- **首页模块化**：后台「首页管理」的**栏位**分两种：**侧面**（钉在视口里跟随滚动，同一格的模块一起钉）和**固定**（随页面滚）—— 在左栏选，手机档一律随页面滚（屏幕太窄）。**只有这几列里最后一格才能当侧面**：下面还占着同样列的模块会滚上来压在它身上，所以被挡住时会说明是哪个模块挡的，并给一个「把下面这一列的模块并进来」的动作（一次把这一列收成一条侧面栏）。后台「首页管理」的画框就是**真前台视口**（电脑 1440×900 / 手机 390×844，可缩放到窗口大小），预览与前台用的是同一套渲染与布局计算；**画布里的卡片/链接只用于看效果，点它不会跳走**，电脑/手机两套模块大小独立配置（其它文案配置共用）。模块盒子先定尺寸，内部按容器重排；宽屏两侧留白。**拖动排序**：拖到两个模块中间会**插进去**（不会"附着"上去），拖到某个格子里会**并进同格**（可以落在同格的第几位），拖到最上/最下就是插到开头/末尾；拖动时手柄跟着指针、目标位置有描边与文字提示（「并入第 N 行 · 第 M 位」/「新起一行」），按住不动靠近画框上/下沿会**自动滚动**去够看不见的位置，按 Esc 取消。可拖右缘改宽（同格一起改）、拖下缘**改高（单位是像素，0 = 高度自适应随内容长）**、超过两种模式可选「自适应 / 固定」，重置当前视口大小。可统一调模块玻璃底和首页背景的不透明度。「欢迎光临」里漂浮色块（泡泡）的文字可在首页管理里按行填写——**最多 24 条**，还能设**「一屏看到几颗」**（3–16，越多越密越小）；泡泡**每次进页面会重新打散顺序**，一屏装不下的依次往上无缝滚动。「模块管理」可新建自己的模块，往里放现成积木或直接写 HTML / CSS / JS。**新建时先选模板**（空白模块 / 图文卡片 / 通栏横幅 / 弹出模块 / 推荐应用），模板给的是一份能直接跑的出厂代码与默认尺寸；**编辑页还能只调「基本样式」**——字体、字号、对齐、正文/标题/背景/强调色、背景图与压暗、圆角、内边距、投影，以及按钮的底色、文字色、圆角、是否占满一行；**没调过的项一律跟随站点主题**（切深浅色也跟着变），调过的才覆盖这一个模块。代码三栏旁边有**导入文件**（把现成的 `.html` / `.css` / `.js` 拉进来，HTML 里的 `<style>` / `<script>` 会自动分到对应栏）与**前台真实观感的预览**。**「推荐应用」是可编辑的内置模块**：不改就是内置那张卡片，一改 HTML / CSS / JS 就整块换成你的版本（有「填回出厂代码」）。**「文章卡片」模块还能在文章之间穿插瞬间卡**：默认一页最多 3 个（填 0 = 关掉），**和文章按发布时间混排**（早的排前面，比本页最后一篇还早的瞬间留到后面的分页）；卡片电脑端占文章卡的一半、内容多才长到满宽，手机端满宽；画三张二级缩略图 + 一段短文案，图片按各自的原始比例排（不相册裁、不拉伸），图多于 3 张时底部渐隐、右下角标「+N」；点卡片直接跳到瞬间页那一条并高亮几秒。首页底部版本信息栏中间可显示站点运行时间（精确到秒），开始时间在「设置」里填，空着则不显示。**两个「浮在最上层」的模块**：**弹出模块**（选左侧 / 右上 / 右下 / 居中提示框出场，可设进页面几秒后出现、关闭叉叉、关掉后本机不再出现，内容是标题 + 正文 + 按钮）与**推荐应用**（自带走秒 + 右上角滑入的白卡：方形应用图标 + 标题 + 一句说明 + 「立即下载」按钮，按钮跳到配置里填的静态下载页，默认 3 秒后出现）。两者都不占格点、按普通模块那样拖位置拉宽窄（宽度按列跨度）、手机端自动变贴底满宽，同侧多个自动错开，默认关闭。**想自己写模块代码就看 [docs/module-html-guide.md](docs/module-html-guide.md)**（能用的 CSS 变量、能复用的类名、覆盖层怎么工作、13 个常见坑、发布前自检）
- **文章能力**：安全 MDX、目录（h1–h6 分层，点击平滑滚动到对应标题；**手机视图里目录排在正文前面**，点右侧圆钮展开其它卡片）、双主题代码高亮、Video、图片灯箱（滚轮/双指放大，同一页再开走缓存）、阅读进度、浏览量 60 秒去重，2 小时签名 cookie 的密码文章；**标题下会给出字数与预计阅读时长**（汉字一字算一个、英文一词算一个，标点与空格不计；按 400 字/分钟向上取整，加密文章不显示）；**文章封面与详情 Banner 现在完全独立**：封面可选图片 / 纯色 / 混色 / 无封面；Banner 可选「与封面一致」（不重复上传）/ 单独图片 / 纯色 / 混色。两者都能单独删除、分别调左右/上下焦点（存成 0–100 百分比），删除 Banner 会自动换成一张随机混色而不是留白。后台可导入 Markdown。**文章页的时间**：三天以内显示「最近 / X 天前」，超过三天改成精确到秒的日期；文章发布后又被改动过，会在同一排用同一字号标出「已修改 + 修改时间」（写文章页设置栏可关掉这个显示）。**作者**：标题下面跟日期同一排、同样的灰字显示作者（笔名）。**一批图可以折叠成一组**：编辑器工具栏点「折叠组」，填个标题、选几张图（或先插空组再往里加），前台就变成**一叠照片**——顶张完整显示，底下几张各露出一条边、还各自歪一点点，像随手摞起来的一摞相纸；**左右滑动**换上面那张，**点一下**展开，展开时**所有照片一起向下滑**、各归其位（想收回去点列尾的「收起」）。图与相册无关，同一批图在这篇成组、在那篇也可以不成组。点开大图看原图；如果这张图归过相册，灯箱右下角会多一个「查看相册」按钮（没归册的图没有这个按钮）
- **相册**：媒体库里的图片可以按相册归类（每张图**只属于一个相册**，也可以在媒体库上方按相册筛选、或看「未分类」）。相册是**独立页面**：前台导航栏「文章」右边的「相册」进 `/albums`（每行两张卡，封面就是这本相册的**一叠照片**——打开时整齐叠在左侧，约 1 秒后从第一张下面依次向右抽出），点进去是 `/albums/{地址名}`（封面大图 + 说明 + 按「卷」分组的照片）。图片按**三档**给：列表用二级缩略图（只本机、默认 320）、详情页（**含封面大图**）用一级缩略图、点开看大图时才加载原图（默认展示阶段一个原图请求都不发）。后台「相册」页可新建 / 改名 / 换地址名 / 写说明 / 排序 / 停用（停用 = 前台 404、文章里的「查看相册」按钮也消失）、从媒体库一次性加入几十张、单张移出、挑封面；**删相册不会删照片**（照片回到「未分类」）。默认按上传时间倒序排。首页还能加一个**相册模块**（默认关闭，在「首页管理」里打开）：把部分相册的照片拼成一条缓慢横向滚动的预览条，点哪张进哪个相册，滚动速度与张数可调；另有**「相册卡片」模块**（同样默认关闭，出厂大小就跟瞬间模块一样——电脑 6 列 × 380px、手机满宽）：**一本相册一张卡**，封面是这本相册的一叠照片（打开约 1 秒后依次向右抽出），下面写标题、张数与照片日期区间，整张卡点进这本相册，可设「只摆哪几本 / 最多摆几本」。注意**相册是对外公开的**：放进相册的图片会在公开相册页可见，即使它只在密码文章里用过
- **评论**：游客昵称两级嵌套、提交后待审；管理员回复直接显示；XSS 按纯文本转义。文章、瞬间、留言板的评论栏都默认收起，点标题才展开
- **瞬间**：单张按原比例完整显示，多张方图（手机上两列，不会挤成一列小图）；点一次展开挤开，再点看原图。首页有瞬间模块（打字机文案 + 本地二级缩略图瀑布；手机上改成上下排，文案至少留三行可见）。**可见范围**：后台可给瞬间设「对外可见期」——默认**永久公开**（不设就等于没这个功能）；在「瞬间」页发布区的**可见范围 → 详细设置**里把全局可见期改成按天数（3 / 7 / 15 / 30 / 90 / 180 / 365 天，或自定义 1–3650 天）后，发布满这些天的瞬间就不再对外展示。还能建若干**可见范围组**（例如「三天可见组」= 3 天、「一个月可见组」= 30 天），发瞬间时逐条挑一个，或「跟随全局可见期」。**两者叠加规则：实际生效 = 其中更短的那个**——全局是整站天花板，分组只能更短不能放宽（全局 7 天 + 一年组，仍然按 7 天）；未分组的瞬间只受全局约束。过期后前台首页、瞬间页、点赞、评论都按「不存在」处理（过期瞬间点赞/评论请求返回 404），**后台仍完整保留内容、评论与点赞**，列表里会标「已过期 · 前台已隐藏」、显示到期时刻与剩余时间，并可逐条改可见范围。删除某个组不会删瞬间：用它的瞬间回落到全局规则（后台会在删除前告诉你影响几条、之后按什么规则显示）。**2026-10 起瞬间能发视频、也能不发文字**：正文留空、只发图片或视频一样能发布（文字与媒体至少有一样）；一条瞬间**最多 1 个视频**，视频与图片可以混排（合计仍受后台「一次最多选几个」上限）。视频在首页瞬间卡、首页瞬间模块和 `/moments` 统一显示**首帧预览**（不是黑块），点开是站点**自绘播放器**（只要播放/暂停、进度条、音量，不用浏览器原生控件；手机竖屏视频会铺满当前视口并带全屏按钮，横屏保持卡片；手机按钮和滑杆都按 ≥44px 触控区做）。站点不为视频生成封面文件，也不把 ffmpeg 装到服务器上。**手机 App 里发视频**：发布区的配图按钮在 App 内弹**自带相册**，能直接挑相册里的视频；相册里多一个**「自动压缩视频」勾选框（默认开）**，视频码率超过 4 Mbps、大小超过 50 MB（或超过站点单文件上限）时先用 App 内置的 ffmpeg 压一遍再上传（顺带把 `.mkv` / `.mov` 这类站点不收的格式转成 mp4），随时可以关掉。**两条硬规则**：**超过 30 分钟的视频一律不许发**（关掉勾选框也拦），压不进站点上限的视频会直接告诉你「太长、请先剪短」，不会让你干等一场压缩。**2026-10-11 起瞬间还能发语音**：发布区多一个**麦克风按钮** —— 网页端点它弹出一条**置顶的录音小条**（左边实时音量波形从左往右长、满 10 秒后整条向左滚，中间计时，右边停止），**按下停止就自动上传**，发布前可以试听、可以删掉重录；一条瞬间**最多 5 条语音、每条最长 5 分钟**（录满自动停），语音不占图片/视频那 9 个名额，展示上单独成一行播放条（不挤进九宫格）。**手机 App 里换成原生录音小窗**：弹出时有一段苹果式动画，停止后**不会直接上传**，而是显示整段波形 —— 可以拖两端**截取想要的片段**、可以**试听**，确认了才回给页面走上传。语音和图片/视频一样进媒体库，但**分开放**：媒体库上方多了「全部 / 图片 / 视频 / 音频」分区，音频卡片能直接播。
- **上传存储**：管理员 CSRF 上传；file-type 魔数校验；**超长文件名会先压到 80 字符，图床把 WebP/AVIF 存成 `.jpg` 也能正常上传**（真实类型仍以内容嗅探为准，跨图片/视频/音频的伪装照旧拒绝）；原图保持原格式，超过 10MB 的图片会先提示再压缩到 10MB 以下作为原图；写文章时先存本地，点发布后才生成一级缩略图并上传 COS。一级缩略图 WebP 本地与 COS 双写；二级缩略图（默认长边 320px）只留本机。本地缓存有上限（默认 512MB）；访客封面/一级缩略图与原图直链 COS。点开原图会先显示模糊缩略图和加载进度，完成后再变清晰；同一页再点同一张直接用缓存。灯箱内可用滚轮或双指放大，放大后可拖动。**顶栏进度条会一路走到「完成」**：压缩、传到服务器、生成缩略图、上传到云存储每一步的百分比都真的在推进（上云那一段报的是真实传输字节，不会卡在某个固定百分比），只往前不回头。**选完图立刻能看**：媒体库、发瞬间、写文章插图与封面都用你本机那份文件做预览，不会为了显示再让服务器把刚传上去的原图发回来一遍（刷新页面后才走服务器地址）。**媒体库上传先预览再上传**：选好文件后弹出的界面里显示的是**你本机的文件**（还没上传），可以逐个移除，并能用自绘的下拉先选「加入哪个相册 / 不加入」、再选「归入哪一卷 / 暂不分类」（没建过卷的相册只有「暂不分类」，不挡上传），点「确定上传」才真正开始传。**COS 完全可选**：不填也能上传、生成缩略图、归入相册、写进文章（文件只存在本机，本地上限也只在有云端副本时才会清缓存，所以自己留意磁盘）；以后配了 COS，用媒体库的「迁移到 COS」补传即可。**在手机 App 里，媒体库的上传按钮会变成两项下拉**（检测到请求来自 SmartBlog App 时）：**相册视图（图片 / 视频）** 走 App 自带相册（视频按上面的规则自动压缩）、**文件视图（图片 / 视频 / 音频）** 仍是系统文件选择器（能选音频）；浏览器里保持原样，点一下直接开文件对话框
- **文章地址**：`/posts/{8 位公开 ID}/{链接名}`，没有链接名时最后一段是 `article`；旧 `/posts/{slug}` 会跳到新地址
- **静态页面**：后台「静态页面」可自己建独立页面（关于我、友情链接、活动页…），每页内容用 HTML / CSS / JS 三栏写（也能直接把现成的静态页贴进来），前台地址是 `/{目录}/{地址名}`。**目录完全自定义**：默认 `pages`，在同一个页面顶部随时改；改名后所有页面的地址一起换新（改之前会先告诉你影响几个页面、旧地址立即失效）。每页可单独停用（停用后前台 404、内容保留）、可删除，页面标题与描述会进 `<title>` 与 meta description，启用中的页面自动进 sitemap。**冲突是硬拦的**：`posts`、`admin`、`api`、`robots.txt` 这些站内已有地址既不能当目录也不能当地址名，后台会直接告诉你跟谁冲突；静态页在 Next 的路由里优先级最低，**框架与站内路由永远优先**，所以将来站里新增栏目（例如 `/notes`）时，同名目录下的静态页会自动让位、不会把新栏目顶掉。这些页面是独立文档，**不套站点的页头页脚**，样式与脚本由你完全掌控（等同于首页自建模块那条「管理员内容面」，只有后台能写，不要在不明来源的代码上偷懒）
- **后台**：`/admin` 登录后可写文章（mdx-editor 可视化编辑 / 预览 / 导入 md；手机上点「设置」从底部打开；分类与标签可在写文章时当场新建并选用）、排首页布局、建自定义模块、管理瞬间/评论/媒体库/**相册**/备份/程序更新/站点设置。侧栏按「概览 / 内容 / 资源 / 系统」分 4 组；**管理员登录后，前台导航栏右侧会出现「外观」入口**（图标紧邻主题切换，访客看不到它），点它进后台并自动展开**右上角的外观弹窗**（从外侧划入）；弹窗可切换 6 套配色（石墨 / 天青 / 藏青 / 松绿 / 绛红 / 赭石，浅色与暗色各一套锚点，换肤无需刷新），并逐张开关概览卡片——关掉的卡片不占位、其余自动重排（其中「快速发瞬间」卡让你在概览页直接发瞬间，和瞬间页的发布区是同一个界面）；每张卡片右上角也能单独隐藏，全部隐藏时有空态与「恢复默认」。**后台标题行不放任何按钮**，深浅主题切换用站点顶栏那一个。手机竖屏用底部 5 项导航（仪表盘/文章/瞬间/评论/更多），列表改成卡片而不是横滑表格。**文章列表点任意一行**会弹出「查看 / 编辑」二选一：查看在新标签打开前台文章页（草稿 / 定时文章还没有公开页面，这一项置灰并说明），编辑进写文章页。更新页还提供「危险操作 → 清空数据」。删除、恢复、立刻重启等危险操作用红字加粗提示。写文章时点「图片 / 视频 / 音频」弹出插入框（上传、从媒体库导入或外链），按住顶部「拖动」换位；外链视频下方标域名；文章可勾选「首页推荐」、可关掉文章页的「已修改」显示；**作者**：写文章页的「作者」框默认带出账号里的笔名，下拉或点标签即可选已登记的笔名，也能直接打字自定义、当场新建笔名（像分类/标签那样可以攒多个）；「设置 → 登录账号」里改默认笔名，文章自己没填作者时就显示它；保存并发布会等图片压缩、生成缩略图和上云全部完成；瞬间多张为方图并可拖动排序，单张按原比例显示
- **安全**：SQL 注入/XSS/CSRF/暴力破解/点击劫持/上传攻击/路径穿越防护；未改初始密码不能调管理 API；密码文评论未解锁不外泄
- **SEO**：sitemap / robots / RSS（密码文不进 RSS）；后台「设置」可填站点地址
- **备份**：在「备份」页设自动周期备份（每几天 + 几点几分，服务器本地时间）与保留策略，到点自动打包数据库+本地上传；同一页也能立即备份、加密开关（可关可开）、上传备份包与预约恢复；包可上 COS——**上云是后台上传的**，本地包一落盘就能离开页面，「位置」列自己从「本地 · 上传中…」变成「本地 + COS」，传失败会给「重试上传」按钮，进程重启打断的也会自动续传；拆分密钥，只拿走文件解不开
- **轻量**：1GB RAM 可运行；SQLite 单文件数据库

## 快速开始（开发）

```powershell
cd main
pnpm install
Copy-Item .env.example .env
pnpm prisma migrate dev
pnpm dev
```

浏览器打开 http://localhost:3000 ，未创建过管理员且没有主机半钥时会进入 **创建站点**（站点名称、管理员、备份口令）；若清空管理员后主机半钥仍在，则进入 **重建管理员**，只需设置用户名和密码，站点配置与备份口令保持不变。无界面时在 `main/` 下执行 `pnpm setup`。没有代码内默认账号，也没有默认站名 MyBlog。

生产不要跑 `pnpm db:seed`。开发若要演示文章：`pnpm db:seed`（幂等，已有文章时不会重复灌入）。清空内容或管理员请在后台更新页使用危险操作，不要直接删除正在使用的 `blog.db`。`pnpm test` / `pnpm dev` / `pnpm start` / pm2 都走 `scripts/boot.cjs`。

后台入口 `/admin`。高级注意见 [docs/user-manual.md](docs/user-manual.md)。

**迁移**（属于高成本操作，请自己执行）：瞬间可见范围、静态页面、文章封面焦点各带一次迁移 —— 建 `MomentVisibilityGroup`（+ `Moment.visibilityGroupId`）与 `StaticPage`，并给 `Post` 加 `coverFocalX/Y` / `bannerFocalX/Y`（默认 50，迁移 `20261012090000_post_focal_points`）与 `coverStyle` / `coverColor` / `coverColor2` / `bannerImage`（迁移 `20261017120000_post_cover_banner_split`）。

- **开发机**：`cd main` → `pnpm prisma migrate dev`（顺带重建 Prisma 客户端）
- **服务器**：走后台「更新」导入新版本就行——`scripts/boot.cjs` 在拉起 Next 之前会自动跑 `prisma migrate deploy`；手工补跑用 `pnpm prisma migrate deploy`，**不要用 `migrate dev`**（它会重建表，本项目被它把 `PostTag` 从 17 行清成 0 行，见 [P-105](docs/pitfalls.md)）

两者都**跑之前先备份 `main/data/blog.db`**，跑完重启一次进程。另外：**带新模型的版本由更新流程自己重建 Prisma 客户端**（`apply-update` 的顺序是 覆盖 → install → migrate deploy → **prisma generate** → build，见 [P-124](docs/pitfalls.md)）；只有**手工**跑 `migrate deploy`（绕过更新流程）或首装 / 换机时才需要自己补一条 `pnpm prisma generate` 再启动。

改样式时想看效果：`pnpm dev` 那个终端别关，另开一个跑 `pnpm shot /posts`（可选 `--measure .post-card --json`）——桌面 + 窄屏各出一张图到 `main/.ui-shots/`，约 2 秒，不碰数据库、不启服务。详见 [docs/pitfalls.md](docs/pitfalls.md) P-086。

## 构建与部署

不要把 Windows 上的 `node_modules`、`.next` 或整仓几 GB 传到服务器。发布物就是程序更新包。空机步骤见 [`main/INSTALL.md`](main/INSTALL.md)。

```powershell
cd main
pnpm pack:update
# 或按标签：pnpm pack:update --git v0.1.2
```

Linux 空机：解压 tar.gz → `bash scripts/install.sh` → 创建站点 → `pm2 start ecosystem.config.cjs`。以后只换包：后台「更新」导入，或按 [Linux 部署 Spec §5.1](docs/linux-deploy-spec.md#51-版本更新本地打包--scp--服务器应用) 的一键顺序：`pm2 stop myblog` → 备份库 → `pnpm apply-update --file ./包.tar.gz`（入库预约）→ `pnpm apply-update --pending --start`（覆盖 + 迁移 + 生成 + 构建）→ `pm2 start myblog`。

生产用 **pm2 fork 单实例**。nginx 必须覆盖 `X-Real-IP`，`client_max_body_size 512m`。1GB 内存请先加 swap。细节见用户手册「部署」。
